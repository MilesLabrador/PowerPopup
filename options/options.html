⚡ PowerPopup — Options

How data access works

PowerPopup reads Dataverse same-origin from an open, signed-in org tab (https://yourorg.crm.dynamics.com) — the same model the Level Up extension uses. No app registration, no tokens, no stored secrets, read-only. Open your org once and it's added to the environment list below automatically.
